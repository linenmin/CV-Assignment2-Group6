Two attack modes on the same frozen V17 EoMT-DINOv3 segmenter
Figure 2. The two attack pipelines we run against V17. (A) Trainable universal generator learns one parameter set theta from the full training distribution, the setup the assignment PDF (Figure 3) describes. (B) Per-image PGD re-optimises a fresh perturbation delta from zero for every test image. Both use the same epsilon budget and the same frozen V17 weights; only the optimisation scope differs. Chapter 4.3 reports that pipeline A fails completely against V17 (mIoU drop ≈ 0) while pipeline B succeeds completely (pixel accuracy 99% → 8%).
